# Carta de Servicio(s)
La idea de la carta de servicio(s) es ofrecer uno o un pakete de servicios. Esta apareceria en las busquedas como un card independiente del proveedor. 

La idea seria algo como esto:
https://servo.com.uy/servicios/24

Algunos de los datos que veo que destacan son:
- nombre del servicio
- descripcion.
- precio
- modalidad
- si el servicio es economico, estandar o premiun.
- cuanto tiempo puede durar
- forma de pago
- horario
- categoria (aca creo que lo miramos como especialidad)
- reseña (seria la del proveedor en general)

## Plan
Mi idea es para el plan publico que se pueda agregar 2 carta de servicio, para el oro 10, y para el platino 20.
