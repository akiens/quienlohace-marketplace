# Imagenes de Galeria y Plan downgrade.

## Que pasa cuando se baja de plan y tienes mas imagenes de las permitidas.
- Las imagenes no se borran hasta pasado 180 dias. 
- Si el plan al que pasa no permite imagenes de galeria entonces estas quedan conjeladas y mostradas en la seccion de imagenes con una nota de cuanto tiempo le quedan para ser eliminadas.
- Si el plan al que pasa permite menos de las que tiene, entonces se dejan en la galaria las permitidas portunidad solo 1 ves de seleccionar con las que quiere permanecer. Una ves que el usuario seleccione y guary se pasa a la seccion de imagenes semiconjeladas. Porque digo semiconjeladas: porque vamos a darle la odadas entoces no se va a dar la opcion nuevamente y las imagenes que no fueron seleccionadas quedan conjeladas. Esto es para evitar de que lo use como un storage.
- Las imagenes conjeladas se van a mostrar y se va poner una advertencia del tiempo que le quedan para que sean eliminadas.
- Si tenemos imagenes conjeladas o semiconjeladas y pasamos a un plan que permite el mismo numero o mas imagenes entonces las desconjelamos y seran usadas normalmente.


## Mostrar u ocultar imagen.
Este feature no tiene nada que ver con el de limite de plan aca simplemente si ocultamos una imagen entonces no la mostramos en el perfil publico. No quiero que la imagen sea movida a ningun lado simplemente muestrala como desabilitada y pasala a la ultima posicion de la galeria. Si se abilita entonces la pasas a la ultima posicion de las imagenes habilitadas.
