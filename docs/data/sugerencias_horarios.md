# Sugerencias de Horarios

Este documento contiene únicamente los textos canónicos y aliases editoriales
utilizados para generar las sugerencias de horarios.

El comportamiento funcional pertenece a **BR-024**. El formato, la generación,
el contrato JSON y el orden del autocompletado pertenecen a **TR-024**.

---

## 1. Formato editorial

```text
- Texto canónico — alias: término1, término2, término3
```

Las secciones y los aliases ayudan a mantener la lista. Su interpretación está
definida exclusivamente en TR-024.
